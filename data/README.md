# Dataset Instructions

This directory contains test data and submission templates for the Kaggle **LLM Classification Finetuning** competition.

Due to GitHub's file size limit (100 MB), the primary training dataset (`train.csv`, ~176 MB, 57,477 battles) is omitted from this repository.

To run the local training pipeline:
1. Download `train.csv` from Kaggle: [LLM Classification Finetuning](https://www.kaggle.com/competitions/llm-classification-finetuning/data)
2. Place `train.csv` in this `data/` directory.
